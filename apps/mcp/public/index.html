Setup

Connect in under a minute.

Obtain a scoped MCP credential from the DailyDraft operator, store it in an environment variable, then register the hosted endpoint with your client.

1 Store the credential in your shell
export DAILYDRAFT_MCP_TOKEN="replace-with-your-scoped-token"
2 Register the hosted MCP server
claude mcp add --transport http dailydraft --scope user https://dailydraft-mcp.vercel.app/mcp --header "Authorization: Bearer $DAILYDRAFT_MCP_TOKEN"

Restart Claude Code after registration, then run /mcp to verify the server and inspect its tools.

1 Store the credential in your shell
export DAILYDRAFT_MCP_TOKEN="replace-with-your-scoped-token"
2 Register the hosted MCP server
codex mcp add dailydraft --url https://dailydraft-mcp.vercel.app/mcp --bearer-token-env-var DAILYDRAFT_MCP_TOKEN

The token is resolved from your environment at runtime and does not need to be written into Codex configuration.

1 Add the server to an MCP client config
[mcp_servers.dailydraft]
url = "https://dailydraft-mcp.vercel.app/mcp"
bearer_token_env_var = "DAILYDRAFT_MCP_TOKEN"
Transport Streamable HTTP
Authorization Bearer token
Protocol mode Stateless JSON

Clients that do not support an environment-backed bearer token can send Authorization: Bearer <token> as an HTTP header. Avoid committing that configuration.

!
Treat MCP credentials like API keys.

Never paste a live token into a chat, issue, source file, or command history. Use a scoped environment variable and rotate the credential if it is exposed.

Capabilities

Useful context, strict boundaries.

Read tools work against the canonical duel API. Prepare tools only return an intent or unsigned transaction for a participant wallet to inspect and approve.

01

Discover the arena

List eligible packs and find open, direct, or house duels by wallet and status.

list_packs · list_duels
02

Verify the result

Read canonical duel state, settlement references, and social-card URLs.

get_duel · get_duel_proof
03

Prepare, never sign

Create validated intents and unsigned devnet funding transactions.

prepare_create_duel · prepare_fund_duel

Non-custodial by design

The agent stops at wallet confirmation.

This MCP never requests seed phrases, stores private keys, signs transactions, submits transactions, holds cards, or settles duels. Value-bearing state should be verified on Solana, not trusted from API text alone.
